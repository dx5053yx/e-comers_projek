## siPandu Design System ("Warung Naik Kelas")

- **Concept**: Digitalized local warung. Familiar to UMKM (WhatsApp, receipts) but professional.
- **Colors**: Use earthy/local tones. Background: #F3EDD8 (kertas coklat). Primary: #1C5C35 (daun pisang tua). Accent: #C8890A (kunyit). Avoid generic SaaS colors (like bright mint green).
- **Typography**: 
  - Sans-serif: `Plus Jakarta Sans` for main text.
  - Monospace: `Space Mono` for nominal values (prices, order codes).
- **Shapes & Motion**: Use specific border radii (sm: 4px, md: 8px, lg: 14px) and asymmetric chat bubble radii.
- **Layout Rules**:
  - **No generic templates**: Avoid 3-column icon grids, numbered steps, or heavy 280px sidebars.
  - **Signature Element**: Use "Chat Bubble" UI as the primary structural unit (for hero sections, tracking, empty states).
  - **Navigation**: Use top-rail navigation on desktop, bottom tab bar on mobile.
- **Empty States**: Always provide actionable context via a small chatbot bubble, never leave a screen entirely empty.
